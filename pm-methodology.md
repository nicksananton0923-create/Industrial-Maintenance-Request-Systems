# PM Methodology — Industrial Electrical Maintenance and Breakdown Analysis

## PM Frequency by Asset Class

| Asset class | Inspection / test | Frequency |
|---|---|---|
| Switchgear (LV) | Visual inspection | Monthly |
| Switchgear (LV) | Thermographic inspection | Annually |
| Switchgear (LV) | Insulation resistance | 3–5 yearly |
| Switchgear (LV) | Contact resistance | 3–5 yearly |
| Switchgear (MV) | Visual inspection | Monthly |
| Switchgear (MV) | Thermographic inspection | Annually |
| Switchgear (MV) | Insulation resistance | Annually |
| Switchgear (MV) | Contact resistance | 3–5 yearly |
| Switchgear (MV) | Protection relay test | Annually |
| Transformer | Oil level check | Monthly |
| Transformer | Thermographic inspection | Annually |
| Transformer | Oil sample (DGA) | Annually (large units) |
| Transformer | Insulation resistance | 3–5 yearly |
| Motor | Visual inspection | Monthly |
| Motor | Bearing inspection (vibration) | Quarterly |
| Motor | Insulation resistance | Annually |
| Motor | Bearing replacement | Per OEM |
| Drive (VFD) | Visual inspection | Monthly |
| Drive (VFD) | Capacitor reforming | Annually (if idle > 1 year) |
| Drive (VFD) | Cooling fan inspection | Annually |
| Panel | Visual inspection | Monthly |
| Panel | Thermographic inspection | Annually |
| Panel | Tightening torque | Annually |
| UPS | Battery test | Quarterly |
| UPS | Battery replacement | Per OEM (typically 5 years) |

(These frequencies are typical; verify against the OEM manual and local regulations.)
